How Dependency Analysis Works

Root Cause Isolation: When an upstream parent (like RTR-01) fails, all dependent clients lose WAN connectivity.

Symptom Suppression: ANG recognizes that downstream clients are merely casualties of the gateway outage, suppressing secondary alerts.

Blast Radius: The exact count and list of devices that will suffer collateral failure if a given node breaks.
